# ScrabbleBot

A Scrabble bot project equipped with developer productivity and context management skills (`ponytail`, `caveman`, and `graphify`).

## Installed Skills

- **Ponytail** (`.agents/skills/ponytail`): Minimalist code generation focusing on small diffs, standard libraries, and avoiding over-engineering.
- **Caveman** (`.agents/skills/caveman`): Terse, token-efficient communication style that eliminates conversational filler while preserving all technical substance.
- **Graphify** (`.agents/skills/graphify`): Local deterministic AST knowledge graph generation and querying for repository structure and context.
